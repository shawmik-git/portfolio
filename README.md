# Md. Shawmik Rahman | Portfolio

Personal portfolio website of a Full Stack Web Developer, built with plain HTML, CSS and JavaScript (a single `index.html`, no build step).

**Live site:** https://portfolio-seven-sooty-94.vercel.app/

## Features
- Fully responsive navbar with a mobile menu and links to every section
- Hero with designation, photo, resume button (opens `resume.pdf`) and social links
- About, Skills (progress bars by category), Education, Experience, Projects and Contact sections
- Project cards with detail pages: tech stack, description, live link, GitHub link, challenges and future plans
- Responsive layout for desktop, laptop, tablet and mobile, with automatic light and dark mode
