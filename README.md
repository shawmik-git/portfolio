# Md. Shawmik Rahman | Portfolio

Personal portfolio website of a Full Stack Web Developer. Built with plain HTML, CSS and JavaScript (single `index.html`, no build step).


## Features
- Responsive navbar with a mobile menu
- Hero with designation, photo, resume button and social links
- About, Skills (progress bars), Education, Experience, Projects and Contact sections
- Project cards with detail pages (stack, description, live link, GitHub link, challenges, future plans)
- Automatic light and dark mode
